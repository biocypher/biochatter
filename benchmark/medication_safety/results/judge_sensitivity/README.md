# Alternative-judge sensitivity analysis

The six alternative judges evaluated the common corpus of 5,120 responses from
the four original response models. This analysis used the direct binary overall
label protocol in `prompts/llm_judge_prompts_legacy_binary.yaml` and was not
combined with the final subcriteria-based DeepSeek scores used for the main
eight-model analysis. Self-evaluations are retained in these sensitivity files
but were not used in the final primary DeepSeek averages.
