# Alternative-judge analysis

## Final manuscript: Supplementary Figure S7 and Table 9

The included judges are GPT-5.4-mini, Qwen3-235B, Kimi K2.6, Gemma 4 31B and
Mistral Large 3. They evaluated the same 3,840 responses generated by Claude
Sonnet 4.6, GPT-OSS-120B and Med42-8B at response-generation temperature 0.
The older GPT-5.4 response corpus, Claude as judge, and the earlier DeepSeek
judge are not included in this analysis.

Two runs per response and criterion were included except for GPT-5.4-mini
evaluations of Claude and Med42, for which one run was included. Thus there are
107,520 criterion-level ratings, representing 19,200 judge-response combinations.
The available data do not establish a prespecified scientific rationale for this
run-count exception; no claim about its cause is made here.

`supplementary_table_9.csv` contains unrounded prompt means. Its final row is an
unweighted descriptive mean of five judges, not an additional judge. Source
aggregates for each judge/model/prompt/criterion are in
`../figure_source_data/supplementary_figure_s7_alternative_judges_source_data.csv`.
Response-level scores were averaged across the available runs and the three
criteria before aggregation; judges receive equal weight despite the run counts.

These judges used the direct binary criterion-label protocol in
`../../prompts/llm_judge_prompts_legacy_binary.yaml`, not the primary DeepSeek
subcriterion JSON protocol. Their inputs included the response-generation
system prompt and patient-attitude condition name. This is not a prompt-blinded
sensitivity analysis. See `../../model_settings/llm_judge_settings.csv` for settings.

## Earlier analyses retained for provenance, not final manuscript results

All other CSVs in this directory describe the older four-response-model,
5,120-response analysis. They can include self-evaluations and earlier judge
versions. Do not use these files to reproduce the final S7/Table 9, or combine
their labels with the primary eight-model DeepSeek results. The old settings
are retained separately in `../../model_settings/llm_judge_settings_legacy.csv`.
